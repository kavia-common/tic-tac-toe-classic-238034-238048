# Frontend (React) - Tic Tac Toe

## Requirements
- Node.js + npm

## Setup
```bash
npm install
```

## Run
```bash
npm start
```

Then open http://localhost:3000

## Features
- 3x3 board
- Local two-player (X/O)
- Win detection (highlights winning line)
- Draw detection
- Reset button
- Responsive layout + keyboard accessible squares
